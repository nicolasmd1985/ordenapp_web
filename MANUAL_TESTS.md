# 🧪 Manual Testing Guide - RSpec Suite

This document provides the necessary commands to run the **Subsidiary** test suite and other RSpec tests manually.

## 🐳 Dockerized Execution (Recommended)

Since the project runs inside a Docker container, you can execute the tests using `docker exec`.

### 🏃 Run All Tests
To run the entire test suite:
```bash
docker exec -it ordenapp_web_container bundle exec rspec
```

### 🎯 Run Subsidiary Specific Tests
To run only the tests related to the Subsidiary model and its GraphQL mutation:

#### 1. Model Spec
```bash
docker exec -it ordenapp_web_container bundle exec rspec spec/models/subsidiary_spec.rb
```

#### 2. Factory Spec
```bash
docker exec -it ordenapp_web_container bundle exec rspec spec/factories/subsidiaries.rb
```

#### 3. GraphQL Mutation Spec
```bash
docker exec -it ordenapp_web_container bundle exec rspec spec/graphql/mutations/subsidiaries/create_subsidiary_spec.rb
```

## 🔍 Troubleshooting

> [!TIP]
> **Check Container Status:**
> Ensure the container is running by checking `docker ps`. If the name `ordenapp_web_container` differs, adjust the commands accordingly.

> [!IMPORTANT]
> **Branch Verification:**
> If you cannot find the spec files in your current branch, they might be in the `agent-21` branch created by the Backend agent. You can switch to it using:
> `git checkout agent-21`

> [!WARNING]
> **Database Locks:**
> If you encounter database errors, ensure the test database is migrated inside the container:
> `docker exec -it ordenapp_web_container bundle exec rails db:test:prepare`
